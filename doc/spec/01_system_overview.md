# 第 01 章：系統總覽與整體架構 (System Overview)

## 1.1 系統願景與定位
**PMS 專案管理與工程 RFI 追蹤系統** 是一套專為大型營造、機電整合與複合型工程打造之敏捷專案管理系統。
系統突破傳統專案軟體僅能管理進度或單一任務的局限，深度融合了：
1. **敏捷可視化看板 (Kanban Board)**：即時掌握施工班組分派、卡片標籤、檢核表與工作負載 (WIP Limit)。
2. **工程需求待釐清追蹤 (RFI Module)**：標準化工地疑義發起、圖說條文引用、預估成本/工期影響評估、受派建築師/顧問主管審查回覆與流水編號追蹤。
3. **高互動時程甘特圖 (Interactive Gantt Chart)**：關鍵里程碑標示、任務間相依性連線、時程縮放與排程同步。
4. **全軌跡稽核與權限控管 (RBAC & Audit Trail)**：詳細記載所有狀態變動、附件上傳與使用者操作歷程。
5. **復古未來終端美學 (Retro-Futuristic Cyberpunk UI)**：提供純黑背景、綠光/琥珀輝光、CRT 掃描線與高對比排版，專為高強度監控與控制台情境設計。

## 1.2 系統技術堆疊

| 層級 | 採用技術 / 套件 | 說明 |
| :--- | :--- | :--- |
| **前端框架** | React 19.0.1 | 採用現代化 Hooks、函數式元件與 StrictMode |
| **開發語言** | TypeScript 5.8.2 | 強型別約束，完整定義資料模型與元件屬性 |
| **建置與打包** | Vite 6.2.3 | 高速 ESM 熱模組替換 (HMR) 與零延遲本機開發體驗 |
| **樣式系統** | Tailwind CSS 4.1.14 | 採用 CSS-First 架構搭配自訂終端主題 CSS 變數 |
| **字型與視覺** | JetBrains Mono, Google Fonts | 等寬字型、CRT 掃描紋理與 Glowing Glow 濾鏡 |
| **圖示與動態** | Lucide React, Motion 12 | 向量終端風格圖示與流暢平移過場動態 |
| **離線儲存機制** | Browser LocalStorage | 本地無伺服器持久化，支援狀態還原與重設 |
