# 第 05 章：看板工作流與工程 RFI 生命週期 (Kanban & RFI)

本章規範看板模組的工作流機制、WIP 限制邏輯以及工程疑義 (RFI) 處置之完整生命週期。

---

## 5.1 敏捷看板工作流 (Kanban Workflow)

### 1. 欄位與階段設計
- 預設四階段工作流程：
  1. **待辦清單 (Backlog / To Do)**：預計展開之工項與工法整備。
  2. **施工中 (In Progress)**：現場已動工或進行中之施工作業。
  3. **品管查驗 (QA & Inspection)**：自主檢查、監造抽查、預埋管線拍照檢核。
  4. **完工驗收 (Done / Accepted)**：經核定驗收完成之工項。
- **WIP 限制防護 (Work-In-Progress Limit)**：
  - 每個階段可個別設定上限數量。
  - 當欄位卡片數量超過 WIP 限額時，終端介面即時以琥珀黃/霓虹紅輝光警告提示，提醒現場避免並行作業過載。
- **卡片互動**：支援跨欄位平滑拖曳重排、快捷展開檢核表、進度條視覺化與優先級標籤。

## 5.2 工程疑義單 (RFI) 生命週期

工程現場疑義從發起到正式解決遵循以下狀態機 (State Machine)：

```
  +---------+
  |  draft  |
  +---------+
       | (發布提請)
       v
  +---------+         (主管指派審查)         +--------------+
  |  open   | ----------------------------> | under_review |
  +---------+                               +--------------+
       |                                           |
       | (建築師/顧問填寫核定答覆)                    | (建築師答覆)
       +--------------------+----------------------+
                            |
                            v
                    +--------------+
                    |   answered   |
                    +--------------+
                       |        |
         (確認圖說無誤/結案) |        | (方案不可行/退回)
                       v        v
                 +--------+  +----------+
                 | closed |  | rejected |
                 +--------+  +----------+
```

### 1. 流水編號規則
- 格式：`{專案代碼}-RFI-{年份}-{三位數流水碼}`
- 範例：`TP2-GREEN-RFI-2026-001`
- 系統透過 `generateNextRfiNumber` 自動依據當年度歷史資料遞增計算，避免人為手動取號重疊。

### 2. 影響評估矩陣
每張 RFI 必須包含兩大關鍵影響評估：
- **成本追加評估 (Cost Impact)**：布林標記是否可能導致合約追加款，並附上預估金額或計算說明。
- **工期要徑評估 (Schedule Impact)**：布林標記是否影響關鍵路徑，並填寫預估延誤工期天數。
- **關聯性綁定**：支援雙向關聯現場具體施工任務（Task ID），讓現場卡片能一鍵跳轉查閱疑義處置進度。
